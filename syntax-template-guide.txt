Java 수업 코드 템플릿 사용 안내

사용법: 영문 입력 상태의 Java 편집기에서 약어 입력 → F9 → 템플릿 선택 → Enter.
현재 Eclipse에는 템플릿 전용 단축키 F9가 등록되어 있습니다. Mac에서 미디어 기능이 작동하면 Fn+F9를 누르세요.
기본 Content Assist: Ctrl+Space. Tab: 다음 수정 칸, Shift+Tab: 이전 수정 칸.
같은 변수명이 여러 곳에 나오면 연결되어 함께 바뀝니다. 마지막에는 Enter로 편집을 마칩니다.
현재 단축키는 Eclipse > Settings > General > Keys에서 Content Assist (Template Proposals)로 확인할 수 있습니다.
템플릿 XML에는 단축키가 포함되지 않으므로 다른 Eclipse에서는 이 명령의 Binding에 F9를 지정하세요.

삽입 위치:
- 문장: main() 또는 다른 메소드의 중괄호 안.
- 멤버: 클래스 중괄호 안이지만 main() 등 메소드의 바깥.
- 클래스: 기존 main 클래스의 마지막 닫는 중괄호 다음.
- 빈 파일: 아직 클래스 내용이 없는 Java 파일.

프로젝트 이름은 main, OJ 제출용 실행 클래스와 파일 이름은 Main / Main.java입니다.
OJ 제출 시 Main.java 내용 전체를 사용하세요. package 선언은 넣지 않고 보조 클래스에는 public을 붙이지 않습니다.
템플릿은 문법 틀이므로 변수명·타입·조건·인자를 문제에 맞게 바꾸어야 합니다.
Scanner와 컬렉션 등 필요한 import는 템플릿이 자동 추가합니다. 같은 스코프에서 같은 변수명을 중복 선언하지 마세요.

다른 Eclipse로 옮기기:
Eclipse > Settings(Preferences) > Java > Editor > Templates > Import...
java-course-templates.xml을 선택하고 Apply and Close.
문법 약어는 j, 롱(통) 약어는 oj로 시작합니다. 이미 등록한 항목을 다시 Import하면 중복될 수 있으므로 교체 시 기존 사용자 항목을 먼저 제거하세요.

  문제 표현: 한 줄에 출력하라 / 각 결과를 줄마다 출력하라 → 이 템플릿 사용
