롱(통) 템플릿 26개 용도와 선택 방법

사용 순서
1. Java 편집기에서 약어를 입력하지 않은 상태로 F9(맥은 Fn+F9)를 눌러 전체 목록을 봅니다.
2. oj로 시작하는 이름과 한글 문제 표현을 보고 고릅니다. 선택하면 프로그램 전체가 삽입됩니다.
3. 실제로 삽입할 때는 기존 코드를 백업한 뒤 Main.java 전체를 비우고, 필요한 oj 약어를 입력해 F9 → 선택 → Enter.
4. 코드 위의 수정할 곳 주석을 따라 상수·조건·입력 순서·출력 문구를 바꿉니다.
5. OJ 제출 전 예시 입력으로 결과를 비교합니다. Main.java / public class Main / package 없음.

목록 표시: 기존 문법 55개와 롱 26개를 모두 Java 문맥으로 통일했습니다.
커서가 메소드 안이든 클래스 밖이든 목록에 표시됩니다. 목록에 보이는 것과 올바른 삽입 위치는 다릅니다.
약어가 이미 입력돼 있으면 그 접두어와 일치하는 항목만 보입니다. 전체를 보려면 빈 위치에서 F9.
문법 템플릿은 삽입 위치 주석을 확인하세요. 롱 템플릿은 파일 전체 교체용이므로 main() 안에 넣으면 안 됩니다.

기본 입력·계산

ojmoney — 단위 환산 금액 계산
  이런 문제: 환율 / 단가를 곱해 금액을 구하라
  바꿀 곳: RATE, 입력 타입, 결과 문자열
  참고 문항: 1주차 2장 문제1

ojdate — 정수에서 날짜·자릿수 분리
  이런 문제: 8자리 생일 / 년 월 일로 나누어라
  바꿀 곳: 나누는 자리수, 출력 형식
  참고 문항: 1주차 2장 문제2

ojcost — 여러 품목의 수량·단가 합계
  이런 문제: 각 메뉴의 수량 / 총 금액을 계산하라
  바꿀 곳: price 배열, 품목 개수, 출력 문구
  참고 문항: 1주차 2장 문제3

ojtravel — 인원에 따른 방 개수·여행비 계산
  이런 문제: 방 하나에 N명 / 숙박비와 항공료 / 공백 포함 여행지
  바꿀 곳: CAPACITY, 비용식, 숙박일과 여행일 구분
  참고 문항: 1주차 2장 문제4

ojcompare — 두 사람의 가중 감점 계산과 비교
  이런 문제: 지각·결석 감점 / 점수가 높은 사람 / 같으면 equal
  바꿀 곳: 기준 점수와 감점 상수, 동점 처리, 출력 문구
  참고 문항: 1주차 2장 문제5

비트와 배열 검색

ojbinary — 2진 문자열의 개별 상태 비트 판별
  이런 문제: 00001101처럼 입력 / 비트 0·1·2·3의 상태
  바꿀 곳: 각 비트 번호, 상태별 출력 문구
  참고 문항: 1주차 2장 문제6

ojbits — 십진 정수에서 상태 비트·하위 비트 값 추출
  이런 문제: 비트 6·7은 상태 / 하위 비트는 온도
  바꿀 곳: 필드 폭 WIDTH와 비트 번호; 원문의 0~5비트와 0~31 표기 충돌 시 시험 조건 확인
  참고 문항: 1주차 2장 문제7

ojlookup — 대응 배열에서 이름으로 값 반복 검색
  이런 문제: 과목명으로 학점 / 없으면 none / stop이면 종료
  바꿀 곳: key·value 배열, 종료어, 미발견 출력
  참고 문항: 1주차 2장 문제8

입력 검증과 반복

ojpositive — 잘못된 입력 제외하며 양수의 합·개수·평균 누적
  이런 문제: -1까지 / 문자열·실수 제외 / InputMismatchException

  참고 문항: 2주차 3장 문제1

ojorder — 메뉴 검색·수량 검증·가격 계산 반복
  이런 문제: 없는 메뉴 / 수량은 양의 정수 / Quit까지 주문
  바꿀 곳: 메뉴·단가 배열, 종료어, 오류 시 남은 줄 소비 정책
  참고 문항: 2주차 3장 문제2

객체·배열·static

ojobject — 입력으로 객체 생성하고 정보 출력
  이런 문제: 필드와 생성자 / TV·상품 클래스 / show 메소드
  바꿀 곳: 클래스명, 필드 타입·개수, 생성자와 show 출력
  참고 문항: 3주차 4장 문제1

ojcuboid — 객체의 치수 초기화·증가·계산·상태 판단
  이런 문제: 직육면체 / increase / 부피가 0인지
  바꿀 곳: 필드와 계산식, 메소드명 volume/getVolume, 문장 끝 마침표

ojaverage — 용량 제한 객체에 양수 저장·출력·평균
  이런 문제: 최대 10개 / 초과는 버린다 / -1 종료 / 평균 한 자리
  바꿀 곳: LIMIT, 입력 허용 조건, 빈 배열 평균 처리, 소수점 자리

ojconcat — static 메소드로 두 배열 연결·출력
  이런 문제: ArrayUtil / concat / 새 배열을 리턴하라
  바꿀 곳: 배열 크기 N·M, 원소 타입, 괄호·공백 출력
  참고 문항: 4주차 4장 문제6

ojdictionary — static 대응 배열·검색 메소드로 사전 만들기

  바꿀 곳: 대응 배열, 종료어, 검색 메소드명과 문구
  참고 문항: 4주차 4장 문제7

상속·인터페이스·다형성

ojcolorpoint — 상속·super·좌표 이동·문자열 표현
  이런 문제: Point를 상속한 ColorPoint / 색과 좌표를 변경하라
  바꿀 곳: 자식 필드, 부모 생성자 인자, toString 형식

ojpoint3d — 상속으로 차원 확장·move 오버로딩

ojthreshold — 부모의 저장 메소드를 재정의해 값 변환
  이런 문제: BaseArray 상속 / 임계값보다 크면 1 아니면 0
  바꿀 곳: SIZE·THRESHOLD, > 또는 >= 조건, 변환값

ojinterface — 인터페이스·default 메소드·객체 배열 다형성

  바꿀 곳: 도형 종류, PI, 입력 개수, draw와 getArea 구현

ojshapes — 부모 클래스 상속·오버라이딩·객체 배열

  바꿀 곳: 부모 메소드 구현, 도형 종류, PI; 원문의 본문 없는 draw 선언은 컴파일 가능하게 수정

ojcalculator — 추상 클래스와 연산별 자식 객체 선택
  이런 문제: Add Sub Mul Div / calculate / 0 나누기 오류면 종료

  바꿀 곳: 필드, 동등성 조건, toString 출력; equals와 hashCode를 함께 수정
  참고 문항: 6주차 6장 문제1

ojgrades — 한 줄 분리·대소문자 정규화·등급 평균

  바꿀 곳: 학점별 점수표, 오류 시 평균 생략 정책, 소수점 자리

  바꿀 곳: 입력 조건, 종료값, 최솟값·최댓값 비교식, 빈 입력 처리

  바꿀 곳: 키·값 타입, 종료어, 자료에 있는 프롬프트 유지 여부
  참고 문항: 9주차 7장 실습2

검증
26개 모두 Java 17로 컴파일하고 예시 입력·출력 검사를 통과했습니다. 유사 문제의 정답은 수정한 조건과 출력에 따라 달라집니다.

자료의 표기 차이
ojbits: 원문의 하위 비트 범위와 온도 값 범위가 서로 달라 WIDTH 주석 확인.
ojpositive: 본문은 평균도 언급하지만 예시는 합·개수만 출력하여 평균 출력은 주석으로 제공.
ojshapes: 원문의 일반 클래스 안 본문 없는 draw 선언에 컴파일 가능한 빈 본문 추가.
ojcuboid: volume/getVolume 명칭 혼용에 대비해 두 메소드 제공.
ojreverse·ojstockmap: 자료에 명시된 >> 등의 프롬프트를 포함하므로 다른 문제에서는 출력 조건 확인.
